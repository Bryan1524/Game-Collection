# Game-Collection-Project
Languages used: C++/C
Application used: Visual Studio Code
Developed a game collection with a menu system that contains 3 different games: Memory card game, Tic-Tac-Toe, and Rock Paper Scissors.
The problem: As I have grown up, all my friends and I have different lives and are no longer able to sit down and play video games together due to work or school. I miss having the opportunity to play competitive games with my friends, so I developed a game collection where I can play some of my favorite games against a computer.
